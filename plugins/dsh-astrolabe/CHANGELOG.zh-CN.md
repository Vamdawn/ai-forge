## [0.1.0] - 2026-10-16

### Added

- 面向 DeepSeek Harness 的实验性标签式侧栏，按 Workspace 或状态（待处理、进行中、已完成）对会话分组，并提供共享的已置顶分区与嵌套的 subagent 会话。
- 可折叠分区、持久化的查看偏好、每个 Workspace 五个空闲会话的配额，以及已完成会话的增量展示。空的 Workspace 标题仍可用于管理。
- 跨会话标题、Workspace 名称与对话内容的内联搜索，支持片段预览、结果数量上限、加载状态和已归档会话的恢复。搜索使用 Host 配置的快捷键，并在聚焦前展开已折叠的侧栏。
- 通过原生目录选择添加 Workspace 并启动会话，同时支持 Workspace 重命名与移除操作。移除 Workspace 注册项会保留其目录与会话日志。
- 兼容的 Host 与第三方会话菜单操作会镜像到侧栏，包括置顶/取消置顶和归档。
- 支持同组内会话拖拽排序与 Workspace 拖拽排序，并持久化手动顺序。已置顶分区和状态分区保留各自的排序规则。
- 简短的位置过渡动画，包括相邻的跨组移动，以及对远处或隐藏目标使用淡出淡入。连续更新会替换当前动画；拖拽和已打开的菜单会保持排序与可见行稳定。滚动和“减少动态效果”偏好会取消动画。
- 当前会话高亮、待输入指示、标题悬停卡片、相对时间、折叠窄栏、键盘导航，以及中英文文案。

### Fixed

- 被替换的菜单和目录选择器注册项即使 ID 与顺序保持不变也会被镜像；Host 释放时会清理已镜像的条目。
- 新的搜索查询会立即丢弃旧的内容匹配。元数据匹配保留片段预览并按最近活动排序；恢复失败时仍可继续操作，并显示内联错误。
- 行操作的键盘事件不再打开其父会话；重命名在输入法组合期间忽略 Enter。
- 跨组拖放会话会被拒绝，“未分组”不会尝试对不存在的 Workspace 重新排序。
- 悬停控件保持行高和时间戳对齐。重新排序会关闭过期的悬停卡片，被打断的动画不会留下可交互的视觉克隆。
- Workspace 分组会为会话行建立索引并复用投影，而不是反复扫描所有会话。

已知限制见 [README.zh-CN.md](README.zh-CN.md#限制)。
