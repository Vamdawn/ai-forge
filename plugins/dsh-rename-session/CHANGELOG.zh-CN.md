## [0.1.0] - 2026-10-13

### Added

- 新增 `@vamdawn/dsh-rename-session`，在 Web 与 Desktop 会话菜单中提供“根据上下文重命名”操作和编辑图标。复用会话的模型与凭据，无需单独的 API key。
- 根据用户与助手的对话文本生成简洁标题，保留压缩摘要，同时过滤辅助指令、目录清单和环境快照。使用对话的主要语言，并锁定已保存的标题以避免自动重新生成。
- 在官方内置的中英文语言环境中提供进度、成功和错误提示，界面语言切换时立即更新。
- 当上下文或模型路由不可用、生成失败或操作被取消时，保留现有名称。处理超时、重复请求、并发重命名以及卸载时的取消；可在不改变当前选中对话的情况下重命名历史会话。
- 提供 TypeScript 的 Host 源码与 TSX 的 Client 源码，具备严格且相互独立的类型检查，并针对 Desktop 兼容的 JavaScript 产物提供自包含构建。包含英文文档、模型指令、安装与发布指南、针对构建后插件的自动化测试，以及分发内容中的 MIT 许可证声明。
